# Font Awesome Configuration

Detected by the Font Awesome agent tools. Commit this file so the whole team benefits.

## Integration

- **Method:** React components via `@fortawesome/react-fontawesome` (individual icon imports, no library registration)
- **Version:** 7.3.1
- **License:** Free
- **Families:** classic

## Defaults

- **Style:** solid (brands for social/brand logos)
- **Family:** classic

## Import Pattern

- Individual imports: `import { faBagShopping } from "@fortawesome/free-solid-svg-icons"` / `import { faInstagram } from "@fortawesome/free-brands-svg-icons"`
- Component: `<FontAwesomeIcon icon={faBagShopping} aria-hidden="true" className="size-4" />`
- `config.autoAddCss = false` + static import of `@fortawesome/fontawesome-svg-core/styles.css` in `src/app/layout.tsx` (App Router flash-of-huge-icon fix). Do not re-import the CSS elsewhere.

## Conventions

- **Scope is deliberately narrow.** The SECRETO brand guide mandates Lucide outline (stroke 1.5) for UI icons and bans filled glyphs. Font Awesome is a registered exception for exactly two cases: **brand logos** (Instagram, WhatsApp — a logo is not redrawn in outline) and the **solid bag on "Agregar al carrito" buttons**. Everything else stays lucide-react. See the deviation register in `docs/ESTADO-Y-SIGUIENTE-SESION.md`.
- Sizing follows the project icon convention: `size-4` inline next to text, `size-5` in ≥44px icon-only controls. Always `aria-hidden="true"` when a text label sits beside the icon.
- Icons inherit `currentColor` — never hardcode fills.
- No kit, no CDN: icons are tree-shaken through the npm packages.
