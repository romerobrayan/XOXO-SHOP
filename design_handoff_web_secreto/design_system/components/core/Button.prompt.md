Boton de accion principal: vino solido para la accion primaria (max 1 por vista), contorno para secundarias, fantasma para terciarias. Siempre uppercase con tracking 1.5px.

```jsx
<Button variant="primario" onClick={add}>Agregar al carrito</Button>
<Button variant="contorno">Ver coleccion</Button>
```

Variantes: primario | contorno | fantasma. Tallas sm/md/lg. Para WhatsApp usa WhatsAppCta, no este boton.
