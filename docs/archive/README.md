# Archive — superseded documents

Everything in this directory describes the **XOXO neon direction**, which the client
replaced with **SECRETO · Boutique Erótica** in July 2026. The palette (magenta `#FF2BC2`
on near-black), the type roles (Instrument Sans + IBM Plex Mono), and the "neon signage
outside" thesis are all dead. Nothing here is a source of design truth.

**The design source of truth is `design_handoff_web_secreto/`** — its README, the tokens
in `design_system/tokens/*.css`, and `design_system/GUIA-DE-MARCA.md` (read the brand
guide before writing any customer-facing copy).

These files are kept, rather than deleted, for one reason: the field research and the
product reasoning in them survived the rebrand even though the visual direction did not.

| File | What is still worth reading | What is dead |
| --- | --- | --- |
| `DESIGN_BRIEF_PDP.md` | Competitor teardown of the Colombian market, the buyer's real questions on a PDP, why sold-out option values stay visible instead of hidden, and why the discounted state is the normal merchandising state here | The entire visual system: palette, type, "neon glow" signature, dark ground |
| `CLAUDE_DESIGN_PLAYBOOK.md` | How a Claude Design session was run for Phase 0 | The opening prompt and the brand it describes. Phase 0 is designed and implemented; there is no session left to run |

Two code comments cite `DESIGN_BRIEF_PDP.md` for its behavioral conclusions
(`src/features/catalog/pickerState.ts`) — those citations point here deliberately.
